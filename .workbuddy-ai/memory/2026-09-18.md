### 「小艺一句话记日记」可行性调研

- 用户诉求：① 对小艺说「帮我记今天的日记，内容是开心，备注是吃了一顿大餐」，小艺自动完成记录；② 进一步说「主题设成瑰粉、字体设成小楷」，小艺改样式并按该样式记录。
- 结论：技术上可行，正确路径是**小艺开放平台「端插件」**，不是 Intents Kit 意图注册。
- 端插件两种执行模式（关键）：
  - **前台执行（AppLink / DeepLink / 标准实现）**：通过 AppLink 拉起应用，参数附在 URI 查询串或 `Want.parameters`，在 `EntryAbility.onCreate/onNewWant` 解析。适合触发操作、页面跳转；无需上架 AGC 即可测试；不支持返回数据。
  - **后台执行（标准实现）**：配置 `resources/base/profile/insight_intent.json` + `module.json5` metadata `ohos.insight_intent`，实现继承 `InsightIntentExecutor` 的类，重写 `onExecuteInUIAbilityBackgroundMode`；返回 `{code, result}` 给小艺播报/卡片。适合查询统计。
- 参数填值机制：大模型依据**工具描述 + 每个输入参数的描述**来决定填什么值。枚举类参数必须在描述里写明映射（如「1=纸墨 … 6=瑰粉」）。AppLink 模式下参数映射类型必须配为 URL，否则参数不会拼进链接。
- 硬约束（决定可行性）：
  - Intents Kit 官方明确「仅面向企业开发者，个人开发者无法进行意图能力申请和注册等操作」；小艺开放平台端插件准入是否同样要求待确认。
  - 端插件创建时「仅支持选择本账号在 AppGallery Connect 中存在的应用 APP 包名」。
  - 仅中国境内（不含中国香港、中国澳门、中国台湾）；HarmonyOS 5.0+；不支持模拟器；Skill 真机测试需 HarmonyOS 7.0 + Beta 版小艺 App。
  - 意图名称受官方垂域 Schema 限制（旅游/优惠/本地生活/金融/医疗/工具等），无「日记」意图，需邮件 agconnect@huawei.com 申请新意图（15 个工作日）。端插件-直接创建路径可绕开该限制。
- 产品设计建议（已告知用户）：写入类操作建议唤起应用后停在 TodayConfirmation 确认页预填参数，保留落字仪式感；传入参数必须过 DiaryTextRules 校验（1—4 字 / 备注 ≤30 字）；当天已有记录时需明确是走修订（消耗唯一一次机会）还是拒绝；主题字体是逐日保存的，语义应定义为「今天用瑰粉」而非改全局默认。
- 相关 Kit：`@kit.AgentFrameworkKit` 的 `FunctionComponent` 可在应用内嵌入智能体入口。

### 「小艺指定相册图片作背景」可行性调研（结论：不建议做）

- 用户诉求：对小艺说「背景是我相册里的第三张图片」，小艺自动把该图设为当天日记背景。
- 结论：**没有一条干净的实现路径，建议不做**。四个独立障碍：
  1. 图片传不过来：端插件输入参数为文本类类型（字符串/数字/布尔/数组/枚举等，示例代码中出现数组），AppLink 是 URI，只能携带文本参数；未找到图片/文件类型的官方说明。
  2. 应用读不到用户相册：鸿蒙媒体库模型下应用免权限仅能读**自己保存到图库**的资源；读用户相册中其他来源的照片需受限权限 `ohos.permission.READ_IMAGEVIDEO`（特殊场景如备份/同步），普通应用拿不到。官方推荐做法是 `PhotoViewPicker`（用户主动选择，免权限）。
  3. 「第三张」语义不成立：相册无稳定序号，新照片插入会改变顺序；应用拿到的排序与用户所见未必一致，传错图比不做更糟。
  4. 与产品定位冲突：让云端模型理解相册内容必须把相册交给云侧，直接违背一字日记「数据仅保存在设备、不上传服务器」的隐私承诺（见已定稿的上架文案）。
- 推荐替代方案（路径三）：端插件只负责唤起应用并预填文本参数，应用在确认页自动调起系统 `PhotoViewPicker`，由用户点选图片。零权限、相册不出端、语义准确，且可直接复用 `Index.ets` 已有的 `chooseBackground()` 逻辑。
- 折中路线（如需减少点击）：① 用语义代替序号（传 `dateHint`/`sceneHint` 文本参数，端侧用媒体库查询 + Core Vision Kit 文搜图匹配，但前提仍是拿到相册读取权限）；② 若小艺支持把图片作为多模态输入传给智能体（未证实，需在平台实际确认参数类型是否有图片/文件选项）。
- **重要修正（上一轮的不确定点已确认）**：云插件当前仅支持企业开发者，**个人开发者可以开发和上架端插件**。上一轮记录的「意图框架仅面向企业开发者」限制只适用于 Intents Kit 意图注册，不适用于端插件路径。
- 前台模式还有 `onExecuteInUIAbilityForegroundMode(name, param: Record<string, Object>, pageLoader: window.WindowStage)`，可在内用 `getUIContext().getRouter().pushUrl({url, params})` 带参跳页——正是「唤起应用停在确认页并预填」的实现方式。工具描述有 2048 字符长度上限，参数描述要写细。
