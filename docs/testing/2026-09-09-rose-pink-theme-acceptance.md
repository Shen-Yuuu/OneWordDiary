# 玫瑰粉第六主题验收

## 已验证

- `StylePresetId` 新增 `rose_pink`，纸张 ID 为 `rose_pink_dev`。
- 主题目录从 5 种扩展为 6 种，主题与纸张 ID 可双向解析且保持唯一。
- 设置页显示“玫瑰粉”和示例字“玫”，通过现有主题目录自动渲染。
- 备份编解码可以接受并恢复玫瑰粉主题，仍不包含背景图片字段。
- 玫瑰粉浅色和深色调色板已接入所有现有 `styleForPaper` 消费方，因此主页、长卷、详情和分享页面无需新增分支。
- `assembleHap` 构建成功。

## 主题颜色

- 浅色：背景 `#F8E8EC`，卡片 `#FFF7F8`，正文 `#3D2930`，强调色 `#B15F76`。
- 深色：背景 `#2A1C22`，卡片 `#35232B`，正文 `#F9EAF0`，强调色 `#D889A1`。
