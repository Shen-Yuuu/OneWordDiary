# 平台托管隐私声明整改验收

## 整改范围

- 删除应用首次启动时展示的自建隐私同意界面。
- 删除自建界面的“同意并继续”“不同意并退出”及本地同意状态逻辑。
- 应用启动后直接进入日记主页，由应用市场的平台隐私托管服务负责首次隐私声明。
- 保留设置页中的“隐私政策”入口，供用户主动查看平台托管的完整隐私政策。

## 验收项目

1. 清除应用数据并首次启动，只出现平台托管隐私声明，不再出现“一字日记”自建同意页。
2. 同意平台声明后进入主页，日记、背景、字体、分享和备份功能正常。
3. 从设置页进入隐私说明，仍可打开平台托管的完整隐私政策链接。
4. 工程源码与测试中不再包含 `PrivacyConsentGate`、`PrivacyConsentViewModel`、`同意并继续`或`不同意并退出`。
