# 节点 7：整体验收与加固记录

- 日期：2026-08-21
- 基线：HarmonyOS 6.0.1 / API 21 / 手机
- 结论：自动化与静态检查通过；真机系统能力仍待验收

## 已通过

- `hvigorw test`：47 个本地单元测试通过。
- `assembleHap`：构建成功，产物为 `OneWord_dev/entry/build/default/outputs/default/entry-default-unsigned.hap`。
- 备份格式固定为 `.oneword`、`format_version=1`，上限 5 MiB（按 UTF-8 字节）和 10000 条。
- 损坏 JSON、未知版本、非法日期、重复日期、超长正文和非法修订状态会在写库前被拒绝。
- 导入只补缺失日期；同日冲突保留本机记录；任一插入失败会整批回滚。
- 本机无记录时恢复备份风格；已有记录时保留本机风格。
- 权限只有 `VIBRATE` 与 `PUBLISH_AGENT_REMINDER`，没有网络和存储权限。
- 生产依赖为空；只有 Hypium 和 Hamock 两个开发测试依赖。
- 未发现网络 API、统计、广告、账号或远程服务代码。
- 日志只记录固定事件名，没有正文、备注、日期或备份内容。
- 未接入 `BackupExtensionAbility`，系统备份恢复框架保持默认关闭；用户备份只通过主动文件选择器发生。
- 导出前和隐私说明均明确 `.oneword` 未加密且包含私人记录。
- 单日/最近七日分享预览、PNG 缓存生成和 Share Kit 系统分享已接通；分享模型不含备注字段。

## 已知非阻断项
