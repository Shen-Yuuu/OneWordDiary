# 紧凑长卷与中轴节点设计

## 目标

- 缩短文字长卷和最近七日分享的纵向长度，减少无意义留白。
- 恢复并强化朱砂色实心节点、正式留白节点和缺失日期节点。
- 两处继续复用相同的长卷节点组件，避免样式再次分叉。

## 方案

采用“共享尺寸规范 + 独立中轴节点层”。不使用整体缩放，也不为分享页复制另一套长卷组件。

共享尺寸调整为：

- 月份标题：48vp。
- 普通记录：88vp。
- 含备注记录：116vp。
- 缺失日期：48vp。
- 分享卡片顶部留白：8vp。
- 分享卡片卷尾：72vp。

长卷文字相应收紧一档：一至四字分别使用 42vp、36vp、32vp、28vp，行高分别为 48vp、44vp、40vp、36vp。日期、正文、备注和短分隔线使用更小的间距与内边距。

## 中轴节点

中轴线是 Stack 的底层；内容位于中间层；节点作为最后一个子节点并设置更高层级，确保不会被正文或日期遮挡。

- 文字记录：10vp 朱砂色实心圆，增加纸色描边，使节点与中轴分离。
- 正式留白：24vp 朱砂色空心圆，中心保留 4vp 朱砂点。
- 缺失日期：14vp 浅灰空心圆。

正式留白和缺失日期的日期信息围绕中轴排列，但不再自行绘制另一套圆形图案。

## 共享与高度计算

- `ScrollRecordNode` 负责月份、内容、中轴和节点的真实布局。
- 新增共享尺寸常量，`ScrollRecordNode` 与 `ShareScrollCard` 使用同一组高度，避免分享卡片计算值与实际节点高度不一致。
- 文字长卷保留点击进入详情、懒加载和触底加载。
- 七日分享保留备注开关；显示备注时仅对应有备注的记录增高到 116vp。

## 验证

- 构建 HAP 并运行 ArkTS 单元测试。
- 在 Local Emulator 检查文字、留白、缺失三种节点均可见。
- 检查月份标题与记录间距明显收紧，单条记录不再占满页面。
- 检查最近七日分享与文字长卷的节点、左右交替和月份标题一致。
- 分别检查七日分享关闭和打开备注后的卡片高度与节点位置。
