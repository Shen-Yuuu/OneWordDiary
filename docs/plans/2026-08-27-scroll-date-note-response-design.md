# 文字长卷日期对齐与七日备注响应设计

## 目标

修复文字长卷中空心节点日期比朱砂节点日期偏左的问题，并让最近七日分享在开启“展示备注”后立即产生明确、正确的内容变化。

## 日期对齐

`ScrollRecordNode` 中朱砂节点、正式留白节点和缺失日期节点继续共享同一条时间轴与左右内容栏。三类日期文字使用一致的字号、字距和内容栏边距。移除空心节点日期文字额外的左右 `8vp` 内边距，使左侧日期的可见右边界与朱砂节点一致。

## 七日备注

“展示备注”开关只控制本次预览与导出的分享图：

- 开启后，所有已记录日期都创建备注区域。
- 有备注的记录显示真实备注。
- 没有备注的已记录日期显示“这条记录没有备注”，确保开关有明确视觉反馈。
- 未记录日期不创建备注区域。
- 关闭后不渲染备注区域。

`ShareScrollCard` 的节点数据和总高度必须使用同一判断条件：`includeNote && item.kind !== ShareDayKind.MISSING`。这样组件内容、时间轴高度和分享图片尺寸保持一致。

## 状态与渲染

保留 `SharePreviewPage` 的 `showNote` 基础状态和 `renderRevision` 重建机制。开关变化后递增版本，七日卡片根据新的 `includeNote` 创建全新节点子树；不增加持久化设置，也不修改日记数据。

## 验证

- 对比文字长卷中左侧朱砂节点和空心节点日期的右边界。
- 在最近七日分享中打开和关闭“展示备注”，确认开关、状态说明和卡片内容同步变化。
- 分别覆盖有真实备注、无备注记录和未记录日期。
- 运行 ArkTS 本地测试和 Debug HAP 编译，并在 Local Emulator 上验证实际布局。
