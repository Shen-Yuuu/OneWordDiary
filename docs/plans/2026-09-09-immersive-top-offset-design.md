# 全屏前景顶部偏移修复设计

日期：2026-09-09。状态：用户已明确指定方案。

## 目标

恢复全屏布局，使页面前景和背景继续扩展到状态栏与底部系统区域；不启用系统安全区自动避让。仅把页面顶部的按钮、日期和标题等前景内容向下移动，避免与状态栏重叠。

## 方案

`EntryAbility` 恢复 `setWindowLayoutFullScreen(true)`，透明状态栏、透明导航栏和深色系统图标保持不变。新增 `app.float.immersive_top_content_offset = 32vp`，作为所有页面共用的手动顶部偏移。

首页编辑/完成态的前景 `Column`、确认页前景 `Column`，以及详情、长卷、设置、备份、隐私和分享预览的前景 `Column` 在现有 padding 中加入该 top 值。背景组件和页面根 `Stack` 不增加 padding，确保照片与主题纸色仍覆盖整个窗口。居中的加载与错误面板不移动；隐私首次同意页已有 48vp 顶部内边距，保持现状。

使用统一资源而不是散落数字，便于真机将 32vp 调整为 28vp、36vp 等。该方案不读取或避让系统安全区，符合用户指定的全屏布局行为。

## 验收

- 全屏窗口调用为 `true`，系统栏继续透明。
- 生产页面顶部偏移均来自 `app.float.immersive_top_content_offset`，没有散落的新固定数值。
- 背景层不获得额外 padding，图片透明度和日记业务不变。
- 全量测试与 Debug signed HAP 构建通过。
- 真机检查首页及所有二级页面顶部不与状态栏重叠；如间距需要微调，仅修改该资源。
