# 一字日记：节点 4.5 真机 UI 二次回正

- 日期：2026-08-21
- 依据：今日编辑、落字确认、首页完成态、文字长卷和设置页真机截图
- 状态：已实现，待真机截图验收

## 目标

保留现代东方留白和现有产品逻辑，修复真机上的确定性显示故障，并适度提高页面信息密度。此次不修改 RDB、Repository、提交、备注、修订、提醒或清空规则。

## 采用方案

采用定向组件回正：不做整套视觉重构，也不只修改几个尺寸值。通过互斥页面结构和统一正文展示组件，消除容易在不同设备密度、字体缩放下复现的测量与裁切问题。

## 页面调整

### 今日与确认

- 确认页与普通今日页互斥渲染，不再叠放，顶部只出现一组日期信息。
- 新建统一正文展示组件，由确认页、首页完成态和单日详情共用。
- 正文组件固定外部舞台高度，正文 `Text` 自身不使用容易裁切的固定高度；1–4 个 grapheme 使用分级字号。
- 首页完成态仍以正文为唯一强焦点，朱砂“已”印章退为辅助信息。
- 备注在编辑页始终可见，在确认页随正文确认，在详情页查看；首页完成态和长卷不显示备注。
- 主按钮使用显式文本子组件，确保墨色背景上的按钮文案在真机可见。
- 编辑页只收紧局部间距并提高弱文字对比度，不改变顶部—中央—底部三段式构图。

### 文字长卷

- 保留月份标题、中轴线和左右错落结构。
- 节点高度适度缩短，日期和正文靠近中轴线，正文视觉增大一档。
- 历史节点仍不显示备注，点击进入详情的行为不变。

### 设置

- 保留现有结构，只整理分区节奏、选择态和危险操作文案。
- 清空最终确认不再要求用户预先备份，因为备份功能在节点 6 才提供。
- 首页右上角设置资源改为更明确的齿轮线性图标。
