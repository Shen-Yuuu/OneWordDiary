# 移除分享备注功能设计

## 目标

移除分享预览中的“展示备注”功能。单日和最近七日的预览卡片、导出图片均不展示备注，也不显示开关或状态提示；日记记录的备注数据和其他页面的备注展示保持不变。

## 方案

采用彻底移除方案：

- 页面删除 `showNote`、Toggle 行及“分享图已展示备注/不展示备注”文案。
- 单日卡片删除备注参数、备注解析、备注区域和调试日志，恢复固定的内容区高度。
- 七日卡片删除备注开关参数、备注解析、动态高度和用于切换的 `ForEach` key；记录节点接收固定的空备注和 `showNote: false`。
- 删除仅服务于分享备注的 `ShareModel` 辅助函数及对应单元测试断言。

## 边界

- `DailyRecord.note`、详情页及编辑页不改动。
- 已解决的分享背景与图片导出代码不改动。
- 缺失日期、正式留白和主内容的既有布局与分享模式不改动。

## 验证

- 分享页不再出现“展示备注”开关和提示文案。
- 单日、最近七日预览及导出图均无备注文本或占位文案。
- ArkTS 编译通过，现有分享数据测试不再依赖被删除的备注展示辅助函数。
