# 每日日记字体选择设计

- 日期：2026-09-12
- 目标：在设置页提供默认字体选择，并在每条日记提交时保存字体快照，使首页、详情、文字长卷和分享图准确呈现当天字体。

## 1. 交互规则

- 设置页新增“字体”区域，提供默认字体、得意黑楷体、呆萌手写体、悠然小楷体、汇文明朝体、云峰飞云体六个选项。
- 选择后立即保存为后续日记的默认字体；当天尚未记录时，编辑和确认界面立即使用新字体。
- 日记提交时把当前默认字体编号写入当天记录。以后修改设置不会改变已经保存的记录。
- 修订已提交日记时，编辑界面使用当前默认字体；修订提交后，该条记录保存当前默认字体。
- 从未选择过字体时使用应用现有的 OneWord Kai 字体。

## 2. 数据与兼容性

- 新建 `FontCatalog.ets`，集中维护稳定字体编号、中文名称、ArkUI family 名称、资源路径及回退规则。
- `AppSettings` 新增 `fontPresetId`，通过 Preferences 的 `font_preset_id` 独立持久化，不与主题颜色绑定。
- 继续使用 `DailyRecord.fontId` 保存每日字体快照，不修改数据库表结构。
- 旧记录中的 `system_serif_dev`、`system_sans_dev` 映射到默认字体，保持历史数据可读；未知编号也回退默认字体。
- 备份 v1 仍只包含文本记录数据，不包含字体文件或背景图片。每条记录已有的 `font_id` 继续导出；导入时独立校验合法纸张编号与合法字体编号，不再要求字体必须与主题成对。

## 3. 字体资源与注册

字体资源固定放在：

`OneWord_dev/entry/src/main/resources/rawfile/fonts/`

本次注册：

| 文件 | 显示名称 | 注册 family |
|---|---|---|
| `OneWordKai-Regular.ttf` | 默认字体 | `oneword_wenkai` |
| `SmileySans-Oblique.ttf` | 得意黑楷体 | `oneword_smiley_sans` |
| `Dymon-ShouXieTi.otf` | 呆萌手写体 | `oneword_dymon_handwriting` |
| `slideyouran-Regular.ttf` | 悠然小楷体 | `oneword_slide_youran` |
| `mingchao.ttf` | 汇文明朝体 | `oneword_mingchao` |
| `YunfengFeiyun.ttf` | 云峰飞云体 | `oneword_yunfeng_feiyun` |

所有 family 都追加 `oneword_wenkai, serif` 回退链。字体注册或字形缺失不会阻止应用启动。

## 4. 展示范围

- 用户字体只用于日记正文和备注，以及设置页的字体预览。
- 日期、标题、按钮、提示语等界面文字继续使用应用字体，保证识别性和布局稳定。
- 首页已保存记录、日记详情、文字长卷、单日分享按记录的 `fontId` 渲染。
- 七日分享的每一天也按各自记录的 `fontId` 渲染；没有记录的占位内容使用默认字体。
- 编辑框和提交确认使用当前设置的默认字体，保证所见即所得。

## 5. 异常处理

- Preferences 中保存了未知字体编号时，加载为默认字体。
- 选择保存失败时恢复上一个选择并显示简短错误。
- 某个字体注册失败时记录日志，渲染通过字体回退链继续工作。
- 清空应用数据后，默认字体恢复为 OneWord Kai。

## 6. 验收标准

1. 六种字体可在设置页选择，重启应用后选择仍保留。
2. 连续多天用不同字体记录后，文字长卷、详情和分享图逐条显示对应字体。
3. 修改默认字体不会改变已提交历史；修订提交会把当前字体保存到该条记录。
4. 旧记录、旧备份可正常读取；包含新字体编号的备份可导入；备份中无字体二进制与背景图片。
5. 字体注册失败或遇到未知编号时页面仍可读。
6. ArkTS 单元测试、代码检查和签名构建通过。
