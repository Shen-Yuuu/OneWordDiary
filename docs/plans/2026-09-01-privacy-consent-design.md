# 一字日记隐私政策入口与首次同意设计

## 目标

在首次使用时要求用户阅读并同意隐私政策；在设置页保留可随时重新查看完整协议的入口。

## 方案

采用“本地同意页 + 系统浏览器打开 AGC 托管协议”的方式。

- 本地同意页展示离线摘要、官方协议链接与“不同意并退出/同意并继续”操作。
- 完整协议固定使用用户提供的 AGC 托管地址：
  `https://agreement-drcn.hispace.dbankcloud.cn/index.html?lang=zh&agreementId=2029714840460753280`。
- 点击查看完整协议时调用系统 URL 打开能力，不在应用内嵌 WebView，因此不增加网络权限，也不改变“日记数据不上传”的产品承诺。
- 同意状态和当前协议版本标识保存在现有 Preferences 设置仓库中；协议版本变化时会再次要求同意。
- 用户未同意时不渲染日记主界面；选择不同意时退出当前 Ability。
- 设置页“隐私说明”入口改为打开完整协议，同时保留简短的本地隐私摘要页面作为补充说明。

## 数据与错误处理

- 仅保存 `privacy_policy_accepted_version`，不保存阅读行为、设备标识或日记内容。
- 若保存同意状态失败，停留在同意页并提示重试，避免错误放行。
- 若系统无法打开链接，显示可复制的协议地址与错误提示；同意操作不依赖浏览器调用成功。

## 验收

1. 全新安装或清空设置后，首次启动进入同意页，不能直接进入日记主页。
2. 同意后重启应用不再弹出；将协议版本常量提高后重新弹出。
3. 设置页可再次打开官方协议。
4. 不同意会退出应用，不写入同意状态。
5. 不增加网络权限，不影响现有本地日记、备份和分享功能。
