# 导入后首页刷新与备注 Emoji 显示修复

## 问题与原因

- 备份导入成功只更新 `BackupViewModel`，根页面的 `TodayViewModel` 没有收到数据变化通知；导航返回也不保证重新触发根页面生命周期，因此首页仍显示导入前的内存状态。
- 备注整体使用日记自定义字体。自定义字体没有 Emoji 字形时会回退到系统彩色 Emoji 字体，两套字体度量差异会让 Emoji 在同一文本组件中异常放大。

## 设计

- `BackupPage` 在 `confirmImport()` 返回成功后触发 `onImportComplete`；`Index` 收到回调后立即重新读取今日记录、记录总数和设置。取消、失败和导出不会触发刷新。
- `GraphemeCounter` 增加字素拆分能力，确保肤色、国旗、组合附加符和 ZWJ Emoji 不被拆开。
- 新增统一的 `DiaryNoteText`：普通文字继续使用记录保存的字体，Emoji 字素使用系统字体，并为二者显式设置同一字号。首页、确认页、详情、文字长卷和分享图共用该组件。

## 验收

1. 本机当天未记录，导入含当天记录的备份；导入成功后不重启应用，返回首页即显示当天记录。
2. 导入失败、取消导入或只导出备份时，首页草稿和状态不被额外刷新。
3. 备注包含普通 Emoji、肤色 Emoji、国旗和 ZWJ 组合 Emoji 时，首页、详情、长卷与分享图的表情字号均与备注文字协调。
4. 普通备注文字仍使用当天保存的字体。
