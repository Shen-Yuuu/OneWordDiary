# 首页、分享与长卷视觉层级回正

## 目标

- 保留现有数据、状态、导航和分享链路，只修正真机上的视觉层级与语义表达。
- 让今日正文重新成为页面主角，并让首页、分享卡和长卷使用一致的文字比例。
- 让最近七日中的写字、正式留白和未记录无需解释即可区分。

## 现状判断

- 正文已经能够正确读取，但首页与单日分享中的 1–4 字实际呈现偏小，页面核心不够明确。
- 开发期使用的通用 `serif` 在真机中文环境下会回退为系统字体，暂时不能依赖它制造宋体气质。
- 七日卡的虚线圆环容易被理解为加载状态；日期太淡，内容与中轴关系不够清楚。
- 长卷中日期和正文的层级接近，中轴较短；只有一条记录时卷尾靠得过近。

## 已确认方案

采用“整体视觉回正”：不增加纹理、字体包或新装饰资源，在当前开发素材范围内调整字号、字重、字距、位置和节点形态。

### 今日完成态

- 正文按 1/2/3/4 个 grapheme 使用明确的四档大字号，固定行高与缩放，避免真机自动压缩或裁切。
- 正文、朱砂“已”印和「见字如面」组成一个紧凑视觉组；印章不再漂浮在远处。
- 日期、修订信息、分享操作和累计天数继续保持弱层级。

### 单日分享

- 保留 286 × 440 的稳定导出尺寸和现有历史风格规则。
- 日期在上、正文居中、品牌落款在下；正文使用与首页一致但略收敛的四档字号。
- 不增加备注、用户标识或额外元数据。

### 最近七日分享

- 写字：朱砂实心小点；正式留白：细圆环加中心点；未记录：淡灰小点或短横，不使用虚线圆环。
- 日期提高可读性，正文提高一级字号；中轴继续存在但降低对比度。
- 七个自然日、历史状态和缺失日期规则不变。

### 文字长卷

- 正文显著大于日期，日期降低对比度，月份标题保持当前层级。
- 中轴贯穿每个记录节点，正文与日期靠近所属节点但不压迫中轴。
- 单条记录仍保留适度卷身长度，让卷尾成为结束标记而不是紧随内容的标签。

## 字体策略

- 本轮不引入外部中文字体文件，避免体积、授权和字符覆盖风险。
- 开发期使用系统中文字体、字重和字距形成克制的纸墨感；保留 `fontId` 和字体映射接口，发布素材到位后可替换。
- 所有正文舞台禁用系统字体缩放对构图的二次影响，同时保留无障碍朗读文本。

## 验证

- 本地测试继续验证正文 grapheme 数量、历史风格、七日状态和分享数据不含备注。
- 完整编译 HAP，确保 ArkTS 和 ArkUI 属性在 API 21 SDK 下成立。
- 真机复拍首页、单日分享、七日分享和 1/2/3/4 字长卷节点；重点检查正文大小、裁切、七日节点语义和单条长卷留白。
