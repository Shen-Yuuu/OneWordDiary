# 页面视觉统一设计

## 目标

- “已”印回到日记正文右上方，不再挤占正文横向空间。
- 首页在题签下方展示已有备注；无备注时不占空间。
- 日期详情与首页使用相同的正文、印章、题签和备注样式。
- 最近七日分享与文字长卷使用相同的月份标题、中轴、左右交替、留白节点和间距。

## 组件方案

### 大字正文

抽取共享的大字正文组件，由首页和日期详情共同使用。组件接收记录类型、正文、字数、备注和字体：

- 正文保持当前按一至四字分档的静态字号，避免 ArkUI 动态字号失效。
- “已”印以叠层方式放在正文区域右上方，使用粗体。
- 正文下方显示“「见字如面」”。
- 备注存在时，在题签下方以小号灰字居中展示；不存在时隐藏。
- 正式留白沿用圆环和朱色小点，但与正文使用相同的舞台尺寸。

首页保留修订状态、分享按钮和累计天数；详情页保留日期与自己的分享按钮。

### 长卷节点

抽取共享的长卷记录节点，由文字长卷页面和最近七日分享共同使用：

- 月份标题、中轴线宽度与颜色、左右交替规则、日期格式、正文字号和分隔线完全共用。
- 正式留白使用相同的圆环节点。
- 七日内没有记录的日期显示为中轴上的浅色空心节点。
- 页面模式可以点击进入详情；分享模式不可点击。
- 分享模式由“展示备注”开关决定是否在对应记录下方显示小号备注。
- 分享卡片只额外保留“卷尾”和应用署名。

## 数据流

- 首页把当天记录的正文、备注和记录类型传给共享正文组件。
- 详情页把查询到的指定日期记录传给同一组件。
- 文字长卷与分享 ViewModel 继续使用现有数据，不修改数据库。
- 两种长卷数据在页面层转换为共享节点所需的显式字段。
- 分享开关状态通过属性传入节点，切换后重建预览卡片。

## 验证

- 构建 HAP，确保 ArkTS 编译通过。
- 覆盖安装到本地模拟器并保留测试数据。
- 检查一至四字正文不会缩小或溢出。
- 检查首页和详情的印章位置、题签与备注完全一致。
- 检查七日分享与文字长卷的节点结构一致。
- 分别检查备注开关关闭和打开时的分享预览。
