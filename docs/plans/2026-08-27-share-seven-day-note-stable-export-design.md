# 最近七日备注与稳定分享导出设计

## 目标

修复“最近七日”分享预览开启“展示备注”后备注文字不显示的问题，并修复加入不透明像素合成后分享图无法生成的问题。导出的 PNG 保留当前视觉内容，同时使用与主页一致的实色背景。

## 最近七日备注

最近七日记录已经从 RDB 正确读取 `note`，问题位于展示层：`ScrollDisplayItem` 已包含 `note` 和 `showNote`，`ScrollRecordNode` 又额外接收 `noteText`，形成两套备注状态。切换“展示备注”时，父组件虽然重建展示项，但节点仍可能读取未同步的独立属性。

修复后由 `ScrollDisplayItem` 作为节点唯一状态源：

- `ShareScrollCard` 根据开关、记录类型和原始备注生成最终备注文本。
- 最终文本和 `showNote` 一起写入新的 `ScrollDisplayItem`。
- `ScrollRecordNode` 只读取 `item.note` 与 `item.showNote`，并据此计算节点高度、条件渲染和无障碍文本。
- 最近七日列表的键继续包含渲染修订号，确保切换后节点子树被刷新。

主页长卷同样使用 `ScrollDisplayItem`，因此移除重复参数后不会改变其数据语义。

## 不透明背景与图片导出

当前失败由新增的高分辨率 `PixelMap` 逐像素处理链路引入。该链路同时持有原始缓冲区、输出缓冲区和新 PixelMap，并依赖设备返回 RGBA/BGRA 像素格式；格式不符、缓冲区尺寸差异或内存压力都会中止分享。

新实现恢复已验证可用的导出路径：组件截图后直接用 `ImagePacker` 编码 PNG，不读取或重建像素。

为保证 PNG 自身有底色，背景在截图之前由卡片组件绘制：

- 分享卡片使用覆盖完整卡片尺寸、无圆角的实体底层。
- 纸墨风底色为主页背景 `#FDF8F7`。
- 素灰风底色为主页背景 `#F7F7F5`。
- 卡片内容、边框和文字位于底层之上；实体层覆盖包括四角在内的全部快照范围，因此导出的 Alpha 不依赖像素后处理。

`OpaquePixelComposer` 及其专用测试不再参与生产路径，予以移除，避免维护一套设备相关的像素格式转换代码。

## 错误处理

- 截图、文件创建、PNG 编码或系统分享任一步失败时，仍恢复 ViewModel 状态并显示现有错误提示。
- 在捕获异常时记录错误阶段和错误内容，便于真机日志定位。
- PixelMap、文件句柄和 ImagePacker 继续在 `finally` 中释放。

## 验证

- 单日分享开启和关闭备注仍保持现有行为。
- 最近七日开启备注后，有备注的记录显示真实内容；无备注的已有记录显示既定占位文案；缺失日期不显示备注。
- 反复切换备注开关时，节点高度、卷尾位置和分享截图同步更新。
- 两种纸张风格导出的 PNG 均显示与主页一致的实色底色。
- 单元测试通过，Debug HAP 构建通过。
