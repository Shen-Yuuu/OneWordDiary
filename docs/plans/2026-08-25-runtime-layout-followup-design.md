# 运行截图复核修正设计

## 已确认问题

- 首页已记录文字仍接近普通正文大小，且“已”印被推到屏幕右侧之外。
- 单日分享的备注开关状态已变化，但卡片没有显示备注或无备注提示。
- 七日分享已有新数据结构，但中轴不明显、记录没有形成清晰的左右交替，未记录日期挤成文本。

## 首页

首页已记录状态不再通过通用 `DiaryWordDisplay` 组件渲染，而是在 `TodayRecordCard` 内直接绘制文字。1 至 4 字分别使用约 190、116、80、58fp，文字区域使用明确宽度并禁止收缩。

文字区域和 64vp 的“已”印组成固定宽度整体，二者禁止压缩，整体水平居中并上下居中。“已”字使用 28fp 粗体。

## 分享备注

分享页维护渲染版本。切换“展示备注”或分享模式时递增版本，以新的组件标识强制重建截图卡片。开启备注后显示真实备注；记录没有备注时显示“这条记录没有备注”。关闭后不渲染备注区域。

## 最近七日长卷

七日长卷在单一卡片组件中直接绘制月份、约 2vp 的中轴、左右交替节点和卷尾，减少跨组件的 index 与状态传递。

已记录日期显示日期、日记大字和可选备注。未记录日期保留为浅色日期与空心节点，保证“最近七日”的连续时间含义，同时使用足够节点间距避免日期堆叠。

## 验证

- 首页用 1 至 4 字数据核对实际字号、整体居中和印章边界。
- 核对单日有备注、无备注、关闭备注三种预览状态。
- 核对七日中记录、留白、缺失日期及跨月布局。
- 执行单元测试、clean 与完整 HAP 构建。
