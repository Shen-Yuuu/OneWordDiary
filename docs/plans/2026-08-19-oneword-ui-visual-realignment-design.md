# 一字日记：UI 视觉回正设计

- 日期：2026-08-19
- 范围：节点 3.5，HarmonyOS 手机端
- 参考：`docs/design/oneword_diary_UI/` 与产品方案

## 目标

将节点 2、节点 3 已完成的业务状态和数据逻辑保留不动，把当前开发骨架式界面回正到“现代东方留白”的视觉方向。实现以原生 ArkUI 为准，不逐字照搬 HTML，也不恢复导出稿中过时的单字限制。

完成后的核心感受应是：安静、克制、具有纸张触感，主字是页面唯一强焦点，导航与次级操作退后，不出现常规表单或双主按钮的工具感。

## 视觉基线

- 页面采用顶部导航、中央内容、底部操作三段式构图；手机宽度内保持 24vp 左右边距。
- 使用暖纸色、墨黑、陶灰和极少量朱砂色；用轻微色阶和透明纹理表达纸面，不使用明显卡片阴影。
- 正文和标题使用可替换的开发宋体映射，日期、说明和按钮使用系统无衬线字体。
- 图标使用本地可替换 SVG 线性资源，保持 1–1.5px 视觉笔画和至少 48vp 触控区。
- 所有主要按钮使用墨色胶囊形；留白、返回、注解等操作使用幽灵按钮或圆形图标按钮。

## 今日页

- 顶部：左侧长卷图标、中央日期与星期、右侧设置图标。
- 中央：灵感位于主字上方但降低对比度；输入区保持足够呼吸空间，1–4 字按数量自适应字号。
- 注解：默认收起，通过圆形线性图标展开；展开后使用单条底线输入，不出现厚重输入框。
- 底部：落字为唯一主按钮；“把今天留给空白”作为主按钮下方的克制文字操作。累计天数置于底部弱信息层。
- 确认、错误、写入中、一次修订和永久定稿沿用相同构图，不改变现有业务状态。

## 长卷与详情

- 长卷使用图标化返回和分享入口，标题居中；保持月份标题、中轴线、正文左右错落、正式留白圆环。
- 历史节点不显示注解，不增加卡片边框；保存时纸张风格只用轻微色阶表现。
- 详情使用极简顶栏、中央大字、朱砂“已”印记和底部圆形分享按钮；注解仅在详情出现。

## 实现边界

- 不修改 Repository、Service、RDB schema 和提交/修订规则。
- 不引入网络字体、运行时下载、账号或新权限。
- 设计稿中的 `maxlength=1`、40 字注解等旧值不进入实现；继续使用 1–4 grapheme 和 30 grapheme。
- 纸张纹理与图标均为可替换开发资源，发布前可无损替换。

## 验证

- 编译 Debug HAP，并执行现有 30 个本地测试，确保视觉改造不破坏状态流。
- 检查空白、输入、注解、确认、完成、修订、长卷、留白详情和错误状态。
- 在当前模拟器尺寸截取今日页、长卷和详情，与导出稿检查构图、层级和操作形态。
- 真机阶段继续验证安全区、大字号、屏幕朗读与 365 条长卷滚动。
